# 第七模块：多 Agent 与 MCP

日期：2026-09-18。模块 ID 为 `multi-agent-mcp`，前置模块保留 `backend-engineering`、`evals-observability-security`。

## 学习能力与课程边界

学习者已经理解工具调用、状态、并发、评测与执行权限。本模块要求学习者能够根据任务依赖选择协作方式，定义委托输入与结果验收，解释 MCP 的角色与请求，处理版本、传输、错误和权限边界，并交付一份可复验的企业资料助手集成说明。

课程使用 2026-07-28 MCP 稳定规范。2025-11-25 仅用于已有系统兼容教学，draft 与可选 extension 单独标注。SDK 的实际支持需要按安装版本核对。课程实验是确定性机制教学；完整网络协议、OAuth 服务和真实模型调用由实际项目的 SDK 与服务承担。

## 资料与课程关系

原始资料包括 Anthropic 的 workflow 与多 Agent 工程文章，LangChain 的协作模式、subagents 与 handoffs 文档，以及 MCP 的当前版本规范。研究记录分别保存实际读取范围、日期、正文主张和限制。所有发布内容在主代理直接核对相关正文后进入资源表。

| 课程 | 核心问题 | 主要产物 |
| --- | --- | --- |

## 实验与图形

1. 依赖与并发调度实验：改变 worker 数量与共享写入对象，实际计算开始/结束时间、总时长和依赖约束。固定任务时长只用于教学，不能预测模型效果。
2. MCP 请求核对实验：检查 2026-07-28 请求必需的 metadata、HTTP 对应字段与能力要求，保留明确的错误类别及版本。完整协议解析由成熟 SDK 负责。
3. 委托权限实验：根据用户权限、委托范围、资源归属、token audience 和具体确认计算是否允许动作，独立展示每层判断。

每课提供两张原创教学图，Mermaid 源码记录关系，安全静态 SVG 提供页面呈现。每张图在真实章节中只有一个 owner，来源必须属于该章节。采用 alt、caption、按顺序的长描述和有标签的局部滚动；通过实际 DOM 检查加载与尺寸。
