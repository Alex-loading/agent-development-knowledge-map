# LLM 基础知识笔记样章设计

## 目标

先把 `llm-01：AI、机器学习与 LLM` 改造成可独立完成学习的知识型主教材，验证内容深度、证据链和页面阅读体验。其余七课继续使用现有 `explanations`；样章通过后，再以同一协议逐课迁移，并把该流程复用于后续模块。

## 内容与证据

- 样章阅读时长为 20–30 分钟，正文目标为约 3000–5000 中文字。
- 章节按“领域地图 → 学习是怎样发生的 → 生成模型与 LLM → 训练与推理 → 模型开发与应用开发 → Agent 开发学习边界 → 总结与下一课”递进，不按资料逐篇摘要。
- `llm-01` 已关联的 7 份资料全部建立来源卡。Microsoft AI for Beginners、Microsoft Generative AI for Beginners 和 Hugging Face LLM Course 承担核心讲解；Agent 课程与 SDK 资料只用于解释应用开发边界；视频或无法获得可靠正文的资料只作为扩展阅读，不支撑关键事实。
- 每个实质章节记录来源 ID。冲突、版本相关结论和证据不足必须显式标注；正文以转述为主，不复制长段原文。
- 现有学习目标、quiz、练习、面试题和完成标准都必须能在样章中找到对应知识，不为追求篇幅加入与 Agent 开发无关的模型训练细节。

## 数据与界面

- `Lesson` 新增可选 `knowledgeNote`：阅读时长、导语、递进章节、提示框、常见误区、总结和下一课衔接。章节包含多个段落、要点及 `sourceIds`。
- `Resource` 新增可选来源卡元数据：权威级别、教材角色、覆盖主题和证据边界。样章先补齐其 7 份关联资料，完整迁移时再覆盖 LLM 模块全部 28 份资料。
- LLM 笔记内容放入独立数据模块，并按 lesson ID 接入课程数据，避免继续膨胀原课程文件。
- 新建通用知识笔记 renderer，展示章内目录、正文、提示/误区、章节依据与扩展资料。课程详情优先渲染 `knowledgeNote`，缺失时回退现有 `explanations`，因此其他课程和模块保持原样。
- 所有正文仍是纯数据，界面只使用 DOM API 与 `textContent`；不引入 Markdown 运行时、第三方依赖或构建步骤。

## 可复用 Skill

在项目 `.agents/skills/build-learning-module-notes/` 创建版本化 Skill。它组合跨来源去重、权威度排序、冲突呈现、逐结论归因、教学目标反向覆盖和章节质量审计，并包含来源政策、章节标准、数据契约与质量量表。

Skill 采用 RED → GREEN → REFACTOR 验证：先让无 Skill 的独立代理处理同一小型资料集并记录浅层罗列、漏引或结构断裂等基线问题；再用 Skill 重跑；最后用另一主题做变体测试。Skill 不安装低信任第三方代码，也不依赖私有凭据。

## 验收

- `llm-01` 在站内能从头读完核心知识，不打开外链也能完成现有 quiz、练习和面试短答。
- 样章不少于 4 个实质章节，阅读时长处于 20–30 分钟；所有章节来源引用可解析，7 份关联资料都有来源卡和明确角色。
- 页面支持键盘访问章内目录与外链，保持一个 `h1`、正确标题层级、移动端无横向溢出，并继续禁止 `innerHTML`。
- 数据测试覆盖新协议、引用完整性和旧内容 fallback；UI 测试覆盖目录、正文、来源与旧课程渲染；全量测试和语法检查通过。
- 用户评审样章的深度、语气、引用密度和阅读体验后，才把相同模板扩展到 `llm-02` 至 `llm-08`。
